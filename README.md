# Football Manager 1.2 — Dificuldade aumentada

Jogo de futebol 2D em português, feito com HTML, CSS e JavaScript.

## Alterações desta versão
- Todos os jogadores do mercado agora custam pelo menos R$ 1.000.
- Preços de contratação: R$ 1.000, R$ 1.500, R$ 2.000, R$ 2.500 e R$ 4.000.
- Melhorias dos jogadores continuam ficando mais caras conforme o nível.
- Rivais ficam mais fortes conforme as partidas avançam.
- A dificuldade recebe aumentos adicionais nas partidas 21, 51 e 101 para representar ligas mais competitivas.
- Os placares continuam limitados a 10 gols por equipe.

## Publicar com GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.

O progresso fica salvo no armazenamento local do navegador de cada jogador.
